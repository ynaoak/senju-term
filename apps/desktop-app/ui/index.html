スレッド

    ワークフロー

    よく使うコマンドをテンプレート化。検索・ショートカット・クイックボタンから実行できます。

      SSH 接続

      接続先を登録。新規スレッド作成時のメニューや下のリストから接続できます。パスワードは保存されません。

        ターミナルプロファイル

        起動するシェルをプロファイルとして管理します。★ が「＋ 新規」で起動する既定です。

          起動セット

          いつも開くシェル・SSH 接続と、そこで実行するワークフローやコマンドをまとめて登録し、ワンクリックで一括起動できます。

            設定

            外観・ターミナル・起動の設定。変更は「保存」で反映され、開いているスレッドにも即時適用されます。

            外観
            ターミナル

            描画を GPU で高速化します。表示が乱れる環境ではオフにしてください(変更は開いているスレッドにも即時適用)。

            bash / zsh / fish の起動時に OSC 133 のプロンプト連携を自動で組み込みます。rc ファイルは変更されません。

            起動

            起動時に、前回開いていたローカルスレッド(プロファイル構成と順序)を再作成します。SSH 接続は認証が必要なため自動再接続せず、SSH パネルや新規メニューから接続します。

            GitHub Releases の署名付きアップデートを起動時に確認します。新しいバージョンがある時だけ通知します(適用するかは毎回確認)。

            AI コマンド支援

            あなた自身の API キーで Anthropic API を直接呼び出します。送信されるのは入力した質問と OS/シェル名のみで、ターミナルの内容や履歴は送信されません。キーはローカルの設定ファイルに保存されます。

            設定・登録データは JSON ファイルとしてアプリ設定ディレクトリに保存されます。
